# Dubhemerak — Hi-Fi Website Wireframe

A clickable, self-contained hi-fi wireframe for the Dubhemerak website redesign. Each page is a standalone HTML file with CSS inlined — no build step, no dependencies beyond one external icon font (Tabler Icons via CDN).

## View it

Open `index.html` in a browser, or enable GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` / root) to get a shareable live link.
